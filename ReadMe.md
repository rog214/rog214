# 👨🏻‍💻 Sobre Mim:
Desenvolvedor Full Stack com foco no ecossistema **.NET** e **Angular**, graduado em Sistemas de Informação (BSI) e atualmente cursando Pós-graduação em Engenharia de Software pela PUC Minas. Atuo na evolução estrutural de um ERP corporativo de grande porte, com entregas de ponta a ponta: desde a modelagem de dados e otimização de consultas no banco Oracle, passando pela construção de APIs RESTful em C#, até o desenvolvimento de interfaces reativas no frontend.

Tenho um forte compromisso com a qualidade do software. Gosto de resolver gargalos de performance nas duas pontas da aplicação e aplico princípios de Clean Code e SOLID para garantir que o sistema cresça de forma sustentável, escalável e fácil de dar manutenção.

🌐 **Conheça mais sobre meus projetos e trajetória no meu portfólio:** [rogerfr.dev](https://www.rogerfr.dev/)
